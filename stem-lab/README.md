# 🧪 STEM Lab

Documentation for the student STEM initiative I am developing at school.

## Purpose

Create a practical environment where students can investigate questions, build things, analyze evidence, and share what they learn.

## Possible activities

- Small research investigations
- Programming workshops
- Data analysis
- Engineering challenges
- Neuroscience demonstrations
- Science communication
- Student project showcases

- What we built or investigated
- Results
- What we learned
